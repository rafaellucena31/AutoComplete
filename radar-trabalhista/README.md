# Radar Trabalhista

Conteúdo informativo para trabalhadores (demissão em massa e jornada),
dentro dos limites do Provimento 205/2021 da OAB.

| Pasta | Entrega |
|---|---|
| `radar/` | Entrega 1: radar diário de demissões (prompt da tarefa agendada e resumos) |
| `pagina/` | Entrega 2: página web com cinco abas |
| `video/` | Entrega 3: vídeo "Sua jornada, seus direitos" (roteiro, quadros, áudio, MP4) |
| `narracao/` | Comparação de vozes (OpenAI e Piper) |

Todo conteúdo jurídico aqui é rascunho para revisão da advogada responsável.
